# No Vibe-Code Clichés

When building any website or UI, **never use any of the following**:

## Visual / Color
- Hush gradients
- Rainbow coloring
- Neon colors
- Basic pastel colors
- Pure white backgrounds
- Purple and black color schemes
- Radial orbs
- Dot grids

## Layout & Components
- Three feature cards in a row
- Bento grids
- Three pricing tiers
- Colored stripes
- Skeleton loaders
- Terminal windows

## Typography & Copy
- M-dashes styled with Inter, Geist, or Space Grotesk as a personality move
- "It's not X, it's Y" framing
- Checkmark bullets
- Fake testimonials
- Emojis as UI elements

## Effects & Animation
- Drop shadow on everything
- Liquid glass
- Hover animations on every single element
- Animated arrows
- Sparkle icons

## Missing / Omitted
- No real product demos
- No Terms of Service
- No Privacy Policy

## Icons & UI Polish
- Lucid icons (as the default icon set)
- Soft corner radius on everything
